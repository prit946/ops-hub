📋 Plan of Action & How to Use

What DriveCore Does

Auto-organizes your entire Google Drive across personal, Pravin's finances, and Store 8181. Moves files to the right folder, renames them consistently, deduplicates, and archives stale files. Nothing is ever permanently deleted — everything goes to Archive.

6-Step Build Process

  • Step 1 — Spec: Done. Architecture and scope approved.
  • Step 2 — Manifest: Tap "Scan Drive" → reads all files, no changes made. Manifest saved to DriveCore/ folder in Drive. Review it before continuing.
  • Step 3 — Taxonomy: Gemini Flash reads manifest → proposes folder structure as JSON. You approve before anything moves.
  • Step 4 — Dry Run: Simulates all moves/renames, outputs log. No actual changes.
  • Step 5 — Execute: Applies changes in batches of 100. Every action logged in Drive.
  • Step 6 — Ongoing: Weekly auto-run. Watches SORT ME folder via webhook for instant trigger.

New Session Setup

  • Open Claude Code → type ctx-get drivecore to load full project context
  • GAS URL: paste once in Settings → saved permanently in gateway KV
  • Gemini key: get free key at aistudio.google.com/app/apikey → paste in Settings
  • Drop zone for new files: SORT ME folder in Store 8181. DriveCore watches it.

Folder Rules (Learned, Not Hardcoded)

  • 01_Business → Store 8181 + Dairy Queen
  • 03_Personal → Prit's docs, vehicles, health, finance
  • 04_Family & Admin → Pravin → IL primary home, 2 rentals, DQ sold 2023
  • Gemini reads file content + name to classify. Taxonomy JSON is the rulebook — editable.

Security

Default first-time PIN: 8181. Change it in Settings → Security. PIN is hashed (SHA-256) and stored locally — never sent anywhere.
