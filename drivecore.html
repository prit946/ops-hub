📋 Plan of Action & How to Use

What DriveCore does

Auto-organizes your entire Google Drive — moves files to the right folder, renames consistently, deduplicates, and archives stale files. Covers: Prit personal, Pravin finances (IL home + 2 rentals + DQ sold 2023), Store 8181 business. Nothing is ever permanently deleted — everything moves to Archive.

New session setup

  • In Claude Code terminal: ctx-get drivecore → loads full context
  • Open ⚙ Settings → paste GAS Web App URL once → saved to CF Worker KV permanently
  • Settings → Gemini key → get free key at aistudio.google.com/app/apikey
  • Default PIN: 8181 — change it in Settings → Security
  • SORT ME folder = drop zone. Webhook triggers DriveCore instantly on file drop.

6-step build process

  • Step 1 — Spec: Done ✓
  • Step 2 — Manifest: Scan Drive → review JSON in Drive → no writes made
  • Step 3 — Taxonomy: Gemini classifies files → proposed folder map → you approve
  • Step 4 — Dry Run: Simulates all moves/renames → review log → no actual changes
  • Step 5 — Execute: Applies approved changes in batches of 100, every action logged
  • Step 6 — Ongoing: Weekly trigger + webhook on SORT ME. Summary after each run.

How DriveCore routes files (learned not hardcoded)

  • 01_Business → Store 8181, Dairy Queen
  • 03_Personal → Prit docs, vehicles, health, finance
  • 04_Family → Pravin → IL home, 2 rentals, DQ archive (sold 2023)
  • Gemini reads filename + content to classify. Taxonomy is a portable JSON config — NAS version uses Ollama instead (same file).

Architecture

DriveCore page → CF Worker gas.proxy → GAS script → Google Drive. No CORS issues. CF Worker stores GAS URL in KV — paste once in Settings, works from any device forever.
